# PrompterCall downloads

A floating teleprompter for your next call. Write local scripts, customize normal and highlighted text, and use optional Voice pace with an elapsed timer.

## Windows

[Download PrompterCall 1.0.0 for Windows](https://github.com/ddbarron48176/PrompterCall-downloads/releases/download/v1.0.0/PrompterCall-Windows-x64.zip)

Free portable ZIP for Windows 10 or later on 64-bit Intel or AMD PCs (x64).

1. Download the ZIP.
2. Choose **Extract All** to extract the entire folder.
3. Open **PrompterCall.exe** from that folder. Keep the accompanying files alongside the app.

This first Windows release is unsigned. Windows may display an unknown-publisher or SmartScreen warning.
